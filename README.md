# DEV.LAB — Where Logic Meets Persistence

An interactive, editorial DSA laboratory and personal archive documenting LeetCode solutions, algorithmic patterns, and consistency metrics.

---

## ⚡ Architecture & Data Flow

DEV.LAB operates strictly via a unidirectional, read-only data pipeline. The frontend never writes back to the source repository.

```
LeetHub Neo (Automated Sync)
            ↓
       problems/            <-- IMMUTABLE SOURCE OF TRUTH (Read-Only)
            ↓
frontend/scripts/generate-data.mjs
            ↓
frontend/src/generated/     <-- Build-time typed JSON artifacts
            ↓
frontend/src/services/repository.ts
            ↓
       React 18 SPA
```

### 🔒 Non-Negotiable Source Integrity Rule

- **`problems/`** is generated and maintained exclusively by **LeetHub Neo** as the single source of truth for problem statements, tags, and Java solution files. The frontend application, scripts, and build processes treat `problems/` as **strictly read-only**. No file inside `problems/` may be manually modified, deleted, moved, or regenerated by the frontend.
- **`frontend/src/generated/`** contains typed JSON artifacts compiled automatically at build time (`summary.json`, `problems-index.json`, `problems-detail.json`, `topics-index.json`). These files should not be edited manually.

## 🛠️ Technology Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite 6
- **Routing**: React Router (HashRouter for universal static hosting resilience)
- **Styling**: Tailwind CSS & Vanilla CSS Design System (`liquid-glass` aesthetics)
- **Icons**: Lucide React
- **Background**: Cinematic local video (`/videos/dev-lab-background.mp4`)

## 🚀 Getting Started

### Prerequisites

- Node.js `>= 18.0.0`
- npm `>= 9.0.0`

### Installation

```bash
cd frontend
npm install
```

### Development

Starts the local development server with automatic data ingestion:

```bash
cd frontend
npm run dev
```

> **Note**: `npm run predev` executes `generate-data.mjs` before the dev server starts, ensuring the catalog is always synchronized with `problems/`.

### Type Checking

Runs static TypeScript compilation checks without emitting files:

```bash
cd frontend
npm run typecheck
```

### Production Build

Compiles and bundles the production-ready static assets into `frontend/dist/`:

```bash
cd frontend
npm run build
```

> **Note**: `npm run prebuild` refreshes `frontend/src/generated/` prior to `tsc && vite build`.

### Production Preview

Locally serves the production bundle from `frontend/dist/`:

```bash
cd frontend
npm run preview
```

## 🌐 Production Deployment

DEV.LAB is designed to deploy seamlessly to any static hosting provider (Vercel, Netlify, Cloudflare Pages, GitHub Pages, AWS S3, or Nginx).

| Configuration | Value |
|---|---|
| **Root Directory** | `frontend` |
| **Build Command** | `npm run build` |
| **Output Directory** | `dist` |
| **Node Version** | `>= 18` |
| **Environment Variables** | None required (fully static, zero runtime secrets) |
| **SPA Fallback** | Natively handled via `HashRouter`; `_redirects` and `vercel.json` included for hosting rewrites |
